# Тестовое задание: мини-карточка лида для CRM

Простая веб-страница для добавления лида. Данные хранятся в `localStorage` и не пропадают после обновления страницы.

## Как открыть

Откройте файл `index.html` в браузере (двойной клик или Live Server).

Либо из папки проекта:

```bash
# PowerShell
start index.html
```

## Что реализовано

- Форма: имя, телефон, источник, ответственный, этап сделки, переключатель «Запрошено ТЗ», кнопка «Сохранить»
- Валидация: имя и телефон обязательны
- Карточки лидов под формой
- Сохранение в `localStorage`
- **Доп. задание:** кнопка «Изменить этап» в карточке

## Где что в коде

| Что | Где |
|-----|-----|
| Интерфейс (форма и разметка) | `index.html` |
| Стили | `styles.css` |
| Логика кнопки «Сохранить» | `app.js` → `handleSubmit` |
| Сохранение / загрузка данных | `app.js` → `saveLeads` / `loadLeads` |
| Смена этапа сделки | `app.js` → `changeStage` |
| Отрисовка списка | `app.js` → `renderLeads` |

Ключ в localStorage: `crm_leads`.

## Как проверить на демо

1. Открыть страницу
2. Нажать «Сохранить» без имени/телефона — появится ошибка
3. Заполнить форму и сохранить — лид появится ниже
4. Обновить страницу (F5) — лид останется
5. В карточке сменить этап — значение обновится и сохранится
